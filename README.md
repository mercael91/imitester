# 🧪 Имитест — E2E-тестирование с самолечением

Имитест — это **навык AI-агента** (Hermes Agent) и одновременно **автономный скрипт** для
E2E-проверки веб-приложений: видимый браузер (Playwright), самовосстанавливающиеся
селекторы, перехват сети/консоли/`pageerror`, диагностика ошибок на сервере по SSH и
отчёт в JSON.

Пользователь говорит «имитест» — агент сам определяет структуру проекта, настраивает
логин и разделы, открывает **видимый** браузер, проходит по страницам, находит дефекты,
пробует их локализовать и отчитывается.

> Версия 2.0 (октябрь 2026). Скрипт переписан: конфиг вынесен в JSON, добавлены
> логин по форме, ожидание стабилизации контента, `--deep` (ссылки/адаптив/a11y),
> корректные коды возврата и встроенная самопроверка. См. [Что изменилось](#что-изменилось).

## Что в репозитории и чего в нём нет

Публикуется **только универсальная часть**: тестер, пример конфига, самопроверка и
документация. Проектные заметки, адреса, доступы и пароли в репозиторий не входят —
они остаются в локальном профиле автора и в хранилище секретов.

История репозитория начинается с одного чистого коммита: перенос с другого хостинга
делается orphan-веткой, а не клоном с унаследованной историей. Перед публикацией —
скан по всем коммитам, а не только по текущим файлам.

## Быстрый старт

```bash
pip install playwright paramiko
playwright install chromium

# 1. Скопировать пример конфига и поправить под проект
cp imitester.example.json project.json

# 2. Запустить (окно браузера будет видно)
python imitester.py --config project.json

# 3. Полный прогон: ссылки, адаптив (390/768/1440), a11y-минимум
python imitester.py --config project.json --deep

# 4. Отчёт
cat imitester_screenshots/report.json
```

Параметры CLI:

| Флаг | Что делает |
|---|---|
| `--config FILE` | JSON-конфигурация проекта |
| `--url URL` | переопределить `base_url` |
| `--deep` | + проверка ссылок, адаптив на 3 ширинах, a11y-минимум |
| `--headless` | без окна (CI); по умолчанию браузер видимый |
| `--shots DIR` | каталог скриншотов и `report.json` |
| `--keep-open` | оставить браузер открытым до Enter (посмотреть глазами) |
| `--json` | напечатать итог в JSON для автоматизации |

Коды возврата: `0` — ошибок нет, `1` — есть `failed`, `2` — критическая ошибка запуска.

## Установка как навыка Hermes

```bash
# Вариант 1: установить файл навыка
hermes skills install https://raw.githubusercontent.com/mercael91/imitester/main/SKILL.md

# Вариант 2: скопировать каталог в профиль
git clone https://github.com/mercael91/imitester.git /tmp/imitester
mkdir -p ~/.hermes/skills/software-development/simulation-testing
cp /tmp/imitester/SKILL.md ~/.hermes/skills/software-development/simulation-testing/
cp /tmp/imitester/imitester.py ~/.hermes/skills/software-development/simulation-testing/templates/
```

После установки навык подгружается автоматически по ключевым словам «имитест»,
«E2E», «прогони тесты». Агент адаптирует конфиг под проект сам: логин, разделы,
селекторы, SSH-доступ.

## Конфигурация

Полный пример — [`imitester.example.json`](imitester.example.json).

```json
{
  "name": "Мой проект",
  "base_url": "https://app.example.com",
  "viewport": {"width": 1440, "height": 900},
  "screenshot_dir": "imitester_screenshots",
  "timeout_ms": 20000,
  "login": {
    "enabled": true,
    "url": "/login",
    "steps": [
      {"fill": "input[name='email']", "value": "user@example.com"},
      {"fill": "input[name='password']", "value_env": "IMITEST_PASSWORD"},
      {"click": "button[type='submit']"},
      {"wait_url": "**/dashboard*"}
    ]
  },
  "sections": [
    {"name": "home", "url": "/"},
    {"name": "chat", "url": "/chat", "settle_ms": 60000}
  ],
  "skip_click_regex": "удал|delete|выход|logout|оплатить|pay",
  "ssh": {"enabled": false, "host": "", "user": "", "key": "~/.ssh/id_ed25519",
          "sudo": false, "allow_restart": false},
  "services": {"backend": "systemctl restart backend"}
}
```

Ключевые моменты:

- **Пароли не храните в файле.** `value_env: "IMITEST_PASSWORD"` берёт значение из
  переменной окружения; если она пустая — шаг логина падает с явной ошибкой.
- **`base_url` + относительные пути.** `page.goto()` в Playwright не принимает
  относительные URL — имитест склеивает их через `urljoin` сам.
- **`settle_ms`** — сколько максимум ждать стабилизации текста страницы. Для страниц с
  AI-ответами (стриминг) ставьте 60000–90000.
- **`skip_click_regex`** — кнопки, которые тестер не нажимает (разрушающие действия).
- **SSH-диагностика только читает** логи (`journalctl`) и ищет совпадения в коде.
  Рестарт сервиса — только при `ssh.allow_restart: true`. Автоматических правок
  кода тестер не делает: «автофикс» = локализация причины, а не `sed` по проекту.

## Что проверяется

| Уровень | Проверка |
|---|---|
| 1 | Загрузка раздела, стабилизация контента, скриншот |
| 2 | Сбор элементов: inputs, buttons, links, images |
| 3 | Inputs: `disabled`, наличие label/`aria-label`/placeholder |
| 4 | Buttons: клик, реакция, возврат на страницу, пропуск опасных действий |
| 5 | Сеть: все `4xx/5xx` (перехват `page.on("response")`) |
| 6 | JS: `console.error` и `pageerror` (непойманные исключения) |
| 7 | `--deep`: битые ссылки, горизонтальный оверфлоу на 390/768/1440, `img` без `alt`, `h1`, `<title>` |
| 8 | Локализация 5xx: SSH → журнал → классификация (`MissingGreenlet`, `ImportError`, …) → grep кода |

## Отчёт

`report.json` рядом со скриншотами:

```json
{
  "timestamp": "2026-10-20 11:01:01",
  "config_name": "Мой проект",
  "base_url": "https://app.example.com",
  "deep": true,
  "total_elements": 184,
  "passed": 31, "auto_fixed": 0, "warnings": 3, "failed": 2,
  "duration_sec": 17,
  "console_errors": [{"section": "errors", "text": "Тестовая ошибка консоли"}],
  "network_errors": [{"section": "errors", "status": 404, "url": "http://…/api/missing"}],
  "page_errors":    [{"section": "errors", "text": "Error: Тестовый pageerror"}],
  "results": [
    {"section": "login", "element": "login", "status": "passed", "screenshot": "shots/01_login_ok.png"}
  ],
  "screenshots_dir": "…/imitester_screenshots"
}
```

Статусы: `passed`, `warning` (не дефект, но стоит посмотреть), `failed` (дефект),
`auto_fixed` (причина локализована через SSH).

## Принципы

1. **Visible, не headless.** Видимый браузер даёт полный DOM, перехват всех запросов,
   консоль в реальном времени, `pageerror` и скриншоты. `--headless` — только для CI.
2. **Не закрывать браузер слишком рано.** Ответ AI-агента может идти 10–90 секунд:
   тестер ждёт стабилизации текста (`wait_for_stable`), а не фиксированные 2 секунды.
   Ложноположительный «✅» хуже честного «⏳».
3. **Элемент не найден — это WARNING, а не FAIL.** UI мог измениться намеренно;
   SmartSelector перебирает 7 стратегий (`role` → `has-text` → `textbox` → …).
4. **Source of truth — код на сервере.** Локальная копия может быть устаревшей:
   диагноз строится по журналу и `grep` на машине, где реально работает приложение.
5. **Ничего разрушающего без явного разрешения.** Опасные кнопки пропускаются,
   сервисы не перезапускаются без `allow_restart`, код не правится автоматически.

## Самопроверка

В репозитории есть встроенный стенд: он поднимает локальный сайт с заложенными
дефектами и проверяет, что имитест их действительно находит.

```bash
python selftest/run_selftest.py
```

Ожидаемый вывод — 8 зелёных пунктов: логин, `pageerror`, сетевой 404, `console.error`,
`img` без `alt`, битая ссылка, пройденные разделы, скриншоты. Если тестер «слепнет»,
самопроверка падает первой.

## Что изменилось

**2.0 — октябрь 2026**

- Переписан `imitester.py`: конфиг вынесен в JSON, реальные коды возврата, читаемая структура.
- Починен дефект, из-за которого прогон падал на первой же кнопке
  (`page.goto(...).__exit__(...)`).
- Относительные пути разделов теперь склеиваются с `base_url` (`urljoin`) —
  раньше `page.goto("/login")` ронял прогон.
- Добавлен шаг логина по форме (`fill` / `click` / `wait_url` / `wait_text`), пароль из env.
- Добавлено `wait_for_stable` — ожидание стабилизации контента вместо фиксированной паузы.
- `--deep` больше не пустышка: битые ссылки, адаптив 390/768/1440, a11y-минимум.
- SSH-диагностика стала read-only; рестарт сервиса — только по флагу.
- Отфильтрован шум: `favicon` и дубли сетевых ошибок в консоли не считаются дефектами.
- Добавлена самопроверка на локальном стенде (`selftest/`).
- SKILL.md синхронизирован с текущей версией навыка: правила visible-браузера,
  ожидание стриминга, безопасность экспериментов на рабочей машине.

## Ограничения

- Тестер **не заменяет** юнит-тесты: он проверяет, что интерфейс жив, а не что бизнес-логика верна.
- «Автофикс» — диагностика причины (журнал + grep), а не автоматическая правка кода.
- Сценарии с CAPTCHA, 2FA и внешними редиректами требуют участия человека.
- Глубокие проверки БД и миграций делаются вручную/отдельными скриптами.
